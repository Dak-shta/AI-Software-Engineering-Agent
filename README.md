
# AI Software Engineering Agent

An AI-powered software engineering agent designed to assist with real-world software development tasks.

The agent combines **Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), repository-level code understanding, tool calling, and iterative reasoning** to analyze software repositories, identify potential issues, propose and implement code changes, and validate solutions through testing.

## Research Goal

The project explores how LLM-based agents can move beyond simple code generation toward **repository-level software engineering**, where an agent must understand existing code, reason about dependencies, locate relevant files, modify code, and verify whether its changes actually solve the problem.

## Current Focus

* Repository and codebase understanding
* Code retrieval using embeddings
* Retrieval-Augmented Generation (RAG)
* ReAct-style reasoning and tool use
* Automated debugging and bug localization
* Code generation and modification
* Unit-test execution and validation
* Iterative error correction
* Evaluation using software engineering benchmarks

## Tech Stack

**Python · LLMs · RAG · Embeddings · Git/GitHub · Pytest · Groq API**

## Project Status

🚧 **Active Research & Development**
